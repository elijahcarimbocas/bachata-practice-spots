# Cowork Spec - Photos for the Bachata Practice Spots site

You are driving Chrome (work profile is fine, no login needed) to save one real photo of each place below. Elijah will drop them into the site. Follow this exactly.

## Where to save

`~/Documents/bachata-practice-spots/img/`

Name each file with the exact slug in the table, plus `.jpg` (or `.png` / `.webp` if that's what the source gives you). Don't rename anything already in that folder.

## What a good photo is

- The actual place: the building, the gym floor, the plaza, the room. Exterior is fine for rec centers, the floor or room is better.
- Landscape, at least 1000 px wide if the source has it.
- No logos, maps, flyers, event posters, or city seal cards.
- No people's faces up close.

## Where to look, in this order

1. The official page in the table. Right-click the best photo, Save Image As.
2. The place's Google Business Profile photos, but only the ones uploaded by the owner (labeled "By owner"). Skip customer photos.
3. Wikimedia Commons search for the place name. If you use one, write the file page URL and license in `img/CREDITS_COWORK.md`.

If nothing good turns up in all three, skip it and list it in the report. Don't use stock photos of a different place.
